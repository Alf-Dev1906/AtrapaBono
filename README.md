# 🎰 AtrapaBono - Landing Page

Landing page desarrollada como una solución moderna y atractiva orientada a un programa de recompensas para jugadores. Este proyecto representa la versión previa a producción/entrega final del sitio.

## 🚀 Vista previa
Puedes ver el sitio funcionando en vivo aquí: [atrapabonoprueba.netlify.app](https://atrapabonoprueba.netlify.app)

## 🛠️ Tecnologías utilizadas
* **HTML5** / **Semantic HTML** para la estructura de la página.
* **CSS3** / Frameworks o estilos personalizados para el diseño responsivo y visual.
* **JavaScript** para la interactividad del lado del cliente.
* **Netlify** para el despliegue continuo y hosting.

## 📁 Estructura del Proyecto
```text
├── index.html        # Página principal
├── css/              # Hojas de estilo
├── js/               # Lógica e interactividad
└── assets/           # Imágenes y recursos gráficos
